# SPIS Future Oracle Migration Plan & Technical Specification

## 1. Executive Summary

SPIS is designed under the Repository Pattern to allow seamless migration from Firebase Firestore to Oracle Database (via `node-oracledb` and SQL*Plus administration) without rewriting business services or frontend logic.

## 2. Oracle Relational Schema (DDL)

```sql
-- 1. Academic Sessions
CREATE TABLE SPIS_ACADEMIC_SESSIONS (
    SESSION_ID VARCHAR2(64) PRIMARY KEY,
    SESSION_CODE VARCHAR2(32) NOT NULL UNIQUE,
    TITLE VARCHAR2(128) NOT NULL,
    START_DATE DATE NOT NULL,
    END_DATE DATE NOT NULL,
    IS_ACTIVE NUMBER(1) DEFAULT 1 NOT NULL,
    CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
    UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
);

-- 2. Course Structures (BCA, BBA, B.Com, B.A., B.Tech, MCA, MBA)
CREATE TABLE SPIS_COURSE_STRUCTURES (
    COURSE_ID VARCHAR2(64) PRIMARY KEY,
    COURSE_CODE VARCHAR2(32) NOT NULL UNIQUE,
    NAME VARCHAR2(128) NOT NULL,
    TOTAL_SEMESTERS NUMBER(2) NOT NULL,
    DURATION_YEARS NUMBER(2) NOT NULL,
    IS_ACTIVE NUMBER(1) DEFAULT 1 NOT NULL,
    CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
);

-- 3. Users & Roles
CREATE TABLE SPIS_USERS (
    USER_ID VARCHAR2(128) PRIMARY KEY,
    EMAIL VARCHAR2(256) NOT NULL UNIQUE,
    DISPLAY_NAME VARCHAR2(128) NOT NULL,
    ROLE VARCHAR2(32) NOT NULL CHECK (ROLE IN ('ADMIN', 'TEACHER', 'STUDENT')),
    IS_ACTIVE NUMBER(1) DEFAULT 1 NOT NULL,
    CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
    UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
);

-- 4. Students
CREATE TABLE SPIS_STUDENTS (
    STUDENT_ID VARCHAR2(64) PRIMARY KEY,
    USER_ID VARCHAR2(128) NOT NULL REFERENCES SPIS_USERS(USER_ID),
    ENROLLMENT_NO VARCHAR2(64) NOT NULL UNIQUE,
    ROLL_NO VARCHAR2(64) NOT NULL,
    COURSE_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_COURSE_STRUCTURES(COURSE_ID),
    CURRENT_SEMESTER NUMBER(2) NOT NULL,
    ADMISSION_SESSION_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_ACADEMIC_SESSIONS(SESSION_ID),
    IS_ACTIVE NUMBER(1) DEFAULT 1 NOT NULL
);

-- 5. Teachers
CREATE TABLE SPIS_TEACHERS (
    TEACHER_ID VARCHAR2(64) PRIMARY KEY,
    USER_ID VARCHAR2(128) NOT NULL REFERENCES SPIS_USERS(USER_ID),
    EMPLOYEE_CODE VARCHAR2(64) NOT NULL UNIQUE,
    DEPARTMENT VARCHAR2(128) NOT NULL,
    DESIGNATION VARCHAR2(128) NOT NULL,
    IS_ACTIVE NUMBER(1) DEFAULT 1 NOT NULL
);

-- 6. Subjects Master
CREATE TABLE SPIS_SUBJECTS (
    SUBJECT_ID VARCHAR2(64) PRIMARY KEY,
    SUBJECT_CODE VARCHAR2(32) NOT NULL UNIQUE,
    NAME VARCHAR2(128) NOT NULL,
    COURSE_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_COURSE_STRUCTURES(COURSE_ID),
    SEMESTER NUMBER(2) NOT NULL,
    IS_REQUIRED NUMBER(1) DEFAULT 1 NOT NULL,
    ELECTIVE_GROUP VARCHAR2(64),
    CREDITS NUMBER(2) DEFAULT 3 NOT NULL,
    IS_ACTIVE NUMBER(1) DEFAULT 1 NOT NULL
);

-- 7. Teacher-Subject Assignments
CREATE TABLE SPIS_TEACHER_ASSIGNMENTS (
    ASSIGNMENT_ID VARCHAR2(64) PRIMARY KEY,
    TEACHER_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_TEACHERS(TEACHER_ID),
    SUBJECT_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_SUBJECTS(SUBJECT_ID),
    SESSION_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_ACADEMIC_SESSIONS(SESSION_ID),
    SEMESTER NUMBER(2) NOT NULL,
    IS_ACTIVE NUMBER(1) DEFAULT 1 NOT NULL,
    CONSTRAINT UQ_TEACHER_SUBJ_SESS UNIQUE (TEACHER_ID, SUBJECT_ID, SESSION_ID)
);

-- 8. Sessional Configurations
CREATE TABLE SPIS_SESSIONAL_CONFIGS (
    CONFIG_ID VARCHAR2(64) PRIMARY KEY,
    SESSION_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_ACADEMIC_SESSIONS(SESSION_ID),
    COURSE_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_COURSE_STRUCTURES(COURSE_ID),
    SEMESTER NUMBER(2) NOT NULL,
    SESSIONAL_NUMBER NUMBER(1) NOT NULL CHECK (SESSIONAL_NUMBER IN (1, 2)),
    MAX_MARKS NUMBER(5, 2) DEFAULT 25.00 NOT NULL,
    STATUS VARCHAR2(32) NOT NULL CHECK (STATUS IN ('NOT_CONFIGURED', 'NOT_CONDUCTED', 'ACTIVE', 'COMPLETED')),
    CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
    UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
    CONSTRAINT UQ_SESS_CONFIG UNIQUE (SESSION_ID, COURSE_ID, SEMESTER, SESSIONAL_NUMBER)
);

-- 9. Assessment Records
CREATE TABLE SPIS_ASSESSMENTS (
    ASSESSMENT_ID VARCHAR2(64) PRIMARY KEY,
    STUDENT_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_STUDENTS(STUDENT_ID),
    SUBJECT_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_SUBJECTS(SUBJECT_ID),
    CONFIG_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_SESSIONAL_CONFIGS(CONFIG_ID),
    SESSION_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_ACADEMIC_SESSIONS(SESSION_ID),
    SEMESTER NUMBER(2) NOT NULL,
    SESSIONAL_NUMBER NUMBER(1) NOT NULL,
    OBTAINED_MARKS NUMBER(5, 2),
    MAX_MARKS NUMBER(5, 2) NOT NULL,
    EXAM_ATTENDANCE VARCHAR2(32) DEFAULT 'ATTENDED' NOT NULL CHECK (EXAM_ATTENDANCE IN ('ATTENDED', 'NOT_ATTENDED')),
    CLASS_ATTENDANCE_PCT NUMBER(5, 2),
    ASSIGNMENT_SCORE NUMBER(5, 2),
    PRESENTATION_SCORE NUMBER(5, 2),
    CLASS_INTERACTION_SCORE NUMBER(5, 2),
    SUBMISSION_STATUS VARCHAR2(32) NOT NULL CHECK (SUBMISSION_STATUS IN ('DRAFT', 'FINAL_SUBMITTED')),
    SUBMITTING_TEACHER_ID VARCHAR2(64) NOT NULL REFERENCES SPIS_TEACHERS(TEACHER_ID),
    FINAL_SUBMITTED_AT TIMESTAMP,
    CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
    UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
    CONSTRAINT UQ_STUDENT_ASSESS UNIQUE (STUDENT_ID, SUBJECT_ID, CONFIG_ID)
);

-- 10. Audit Logs
CREATE TABLE SPIS_AUDIT_LOGS (
    LOG_ID VARCHAR2(64) PRIMARY KEY,
    ENTITY_TYPE VARCHAR2(64) NOT NULL,
    ENTITY_ID VARCHAR2(64) NOT NULL,
    ACTION VARCHAR2(32) NOT NULL,
    ACTOR_ID VARCHAR2(128) NOT NULL,
    ACTOR_ROLE VARCHAR2(32) NOT NULL,
    REASON VARCHAR2(512),
    PREVIOUS_DATA CLOB,
    NEW_DATA CLOB,
    TIMESTAMP TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
);
```

## 3. Data Mapping & Type Conversion Matrix

| Firestore Concept | Oracle Relational Equivalent | Conversion / Safety Rule |
|---|---|---|
| Document ID (String) | Primary Key `VARCHAR2(64)` | Stable UUID or natural business key; never auto-increment |
| Timestamp (`admin.firestore.Timestamp`) | `TIMESTAMP` | Converted to ISO-8601 string then parsed to Oracle Timestamp |
| Map / Sub-objects | Child Table or `JSON` / `CLOB` | Structured relations normalized into relational child tables |
| Missing field | `NULL` | Explicitly validated; mandatory keys have `NOT NULL` constraint |
| Boolean `boolean` | `NUMBER(1)` (0 or 1) | Strict boolean mapping with constraint `CHECK (col IN (0,1))` |

## 4. 10-Step Reconciliation & Cutover Protocol

1. **Lockdown & Freeze**: Set system to Read-Only mode to prevent write discrepancies.
2. **Bulk Extract**: Export collections to structured, checksummed JSON artifacts.
3. **Data Type & Schema Pre-check**: Run validator on JSON artifacts against target constraints.
4. **Referential Integrity Validation**: Verify every foreign key (`studentId`, `subjectId`, etc.) has an existing parent.
5. **Detection of Corrupt/Orphaned Records**: Flag records without corresponding session or enrollment.
6. **Parallel Import**: Bulk insert into Oracle staging tables using `node-oracledb`.
7. **Document/Row Count Reconciliation**: Compare `COUNT(*)` in Oracle vs total documents in Firestore.
8. **Mathematical Score Reconciliation**: Run `CalculationService` independently against both datasets; assert exact floating-point matches.
9. **Dual-Run Verification**: Route a subset of read traffic to Oracle and check parity.
10. **Final Cutover & Rollback Plan**: Flip driver flag in config; keep Firestore replica available for 72 hours.
